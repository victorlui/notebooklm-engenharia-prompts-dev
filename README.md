# Engenharia de Prompts para Desenvolvimento de Software com IA

## Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO utilizando o NotebookLM para estudo e consolidação de conhecimento.

O tema escolhido foi **Engenharia de Prompts aplicada ao Desenvolvimento de Software**, devido ao crescente uso de Inteligência Artificial no processo de criação de aplicações web, mobile e backend.

O objetivo é compreender como elaborar prompts eficientes para aumentar a qualidade das respostas geradas por modelos de IA durante tarefas de desenvolvimento de software.

---

# Objetivos de Estudo

* Entender os fundamentos da Engenharia de Prompts.
* Aprender técnicas para melhorar respostas geradas por IA.
* Aplicar IA no desenvolvimento de aplicações.
* Criar prompts reutilizáveis para tarefas comuns.
* Documentar aprendizados e dificuldades encontradas.

# Troubleshooting

## Problema

Respostas muito superficiais.

### Solução

Adicionar:

* Contexto
* Objetivo
* Papel da IA
* Formato esperado

---

## Problema

Código incompleto.

### Solução

Solicitar:

* Estrutura de pastas
* Arquitetura
* Boas práticas
* Testes

---

## Problema

Respostas inconsistentes.

### Solução

Utilizar prompts iterativos e refinamentos sucessivos.

# Miniguia de Estudo

## O que é Engenharia de Prompts?

É a prática de estruturar instruções para modelos de IA produzirem respostas mais precisas e úteis.

---

## Principais Técnicas

### Zero-Shot Prompting

Solicita diretamente a tarefa.

### Few-Shot Prompting

Fornece exemplos antes da solicitação.

### Chain of Thought

Estimula raciocínio passo a passo.

### Role Prompting

Define um papel para a IA.

### Context Enrichment

Fornece contexto detalhado.

---

# 📖 Glossário

## Prompt

Instrução enviada ao modelo.

## LLM

Large Language Model.

## Context Window

Quantidade de contexto que o modelo consegue analisar.

## Hallucination

Informação incorreta gerada pela IA.

## Few-Shot

Técnica baseada em exemplos.

## Chain of Thought

Raciocínio estruturado passo a passo.
